# Wayfinders on the Hudson

Cloud-managed Astro website for Wayfinders on the Hudson. GitHub is the source of truth; normal content work is requested through Codex, reviewed in a pull-request preview, and published only after explicit approval.

## Commands

```bash
npm ci
npm run dev
npm run check
npm run build
npm run preview
```

The project uses Astro, strict TypeScript, Tailwind CSS 4 through its Vite plugin, and static output. See [`docs/architecture.md`](docs/architecture.md) and [`docs/cloud-environment.md`](docs/cloud-environment.md).

## Current status

Phases 0–7 establish a provisional design system and global shell. Brand assets, program content, contact details, external links, Vercel, and production publishing remain intentionally unconfigured.
