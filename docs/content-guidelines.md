# Content guidelines

- Preserve approved wording unless rewriting is explicitly requested.
- Never infer dates, ages, prices, times, locations, names, biographies, or destination URLs.
- Label incomplete material as a placeholder in both the interface and implementation.
- Flag contradictory details for human resolution rather than silently choosing one.
- Prefer direct, welcoming language, descriptive headings, short paragraphs, and meaningful link text.
- Content can have a custom page journey; it does not need to fit a rigid schema.
