# Gwen's editing guide

This guide will be completed in its dedicated later phase. For now, the key workflow is simple: tell Codex which page should change, provide the approved words and images, identify any loose visual reference, state what must stay unchanged, and ask for a preview. Publishing always requires separate, explicit approval of the latest preview.

You do not need to install development software, locate changed files, edit code, or upload files manually. GitHub remains the authoritative website copy.
