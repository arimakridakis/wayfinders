# Image guidelines

- Use only imagery the organization owns or is licensed to publish.
- Record source, permission, subject names where relevant, and intended usage before launch.
- Supply intrinsic width and height to limit layout shift and use responsive `sizes` values.
- Write concise alternative text for informative content; use an empty alternative for purely decorative images.
- Preserve meaningful subjects in mobile crops instead of mechanically applying desktop crops.
- Optimize source assets before committing them; do not upscale small originals.
- The current illustration is explicitly a foundation placeholder, not final photography or branding.
